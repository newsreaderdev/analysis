# stockcorr 量化策略完全指南（从零基础到实盘流程）

本指南从基础概念出发，逐一讲解工具中 26 个指标的原理、目的与用法，并用真实数据
（2013–2018 S&P 500，477 只股票，113,526 对组合）跑出的结果演示如何把它们组合成
可执行的交易流程。

> 文中所有真实数字来自仓库内置漏斗在历史数据上的输出，用于演示**方法论**，
> 不构成任何投资建议。

---

## 0. 两个地基概念

**① 收益率（Return）**：我们几乎从不直接比较股价（AAPL $200 vs KO $60 没法比），
而是比较**每日对数收益率** `r = ln(P_t / P_{t-1})`。所有"相关性"默认指收益率之间的相关性。

**② 价差（Spread）**：两只股票的价格组合 `Spread = A − β×B`，其中 β 叫**对冲比率**。
配对交易的全部秘密：找到让这个价差"有规律"的股票对。

---

## 一、线性相关类

### 1. Pearson 相关系数（`pearson`）

**概念**：衡量两只股票收益率同涨同跌程度，范围 [-1, +1]。协方差除以两者标准差之积。

**目的**：最便宜的第一道筛子——500 只股票 12 万对组合一秒算完，昂贵指标只对高
Pearson 对子算（这就是 `--prefilter` 的作用）。

**作用**：组合分散（买低相关股票降低组合波动）+ 漏斗预过滤。

**交易举例（分散化）**：已持有 NVDA，备选加仓 AMD（相关 ~0.8）或 KO（~0.2）。
各配 50% 时：NVDA+AMD 组合波动 ≈ 单只的 95%（几乎无分散效果，等于芯片仓位翻倍）；
NVDA+KO 组合波动 ≈ 单只的 77%（同样预期收益，回撤更小）。

> ⚠️ **新手最大误区**：相关性高 ≠ 适合配对。两只股票可以收益率高度相关但价格
> 越走越远（一只年涨 30%、一只年涨 10%，每天同向但差距越拉越大）。
> **判断配对要用协整，不是相关性。**

### 2. Spearman 秩相关（`spearman`）

**概念**：先把收益率换成排名再算 Pearson，只关心方向一致性、不关心幅度，免疫极端值。

**用法**：当 Pearson 与 Spearman 差距大（如 0.7 vs 0.3），说明相关性主要由几个极端日
贡献——平时不同步，只是一起崩过几次。**筛选规则：只接受 |Pearson−Spearman| < 0.15 的对子。**

### 3. Kendall's τ（`kendall`）

**概念**：随机取两天，统计"A 与 B 相对走势一致"的比例。与 Spearman 信息高度重叠但更慢。

**建议**：大宇宙（>200 只）直接用 Spearman（工具会发警告）；Kendall 留给小样本
（如月线只有 60 个点）。

### 4. 协方差（`covariance`，含 Ledoit-Wolf 收缩）

**概念**：未标准化的相关性，是 Markowitz 组合优化的直接输入（默认年化 ×252）。

**为什么要收缩**：500×500 矩阵有 12.5 万个参数，5 年数据只有 1,260 天——参数比数据多，
样本矩阵噪声主导。优化器会"精确放大噪声"给出极端仓位。Ledoit-Wolf 把矩阵向简单结构
拉回，用一点偏差换大幅降方差。喂优化器时务必 `shrinkage=True`。

## 二、协整类 —— 配对交易的心脏

### 先理解"协整"：醉汉与狗

醉汉牵狗散步：醉汉走得歪歪扭扭（随机游走），狗也乱跑，**但狗被绳子拴着**——可以暂时
跑远，总会被拉回。醉汉=股票 A，狗=股票 B，**绳长=价差**。单独哪只都不可预测，
但**价差可预测**（总会回归）。两只股票被同一根绳子拴着，就叫**协整**。

什么股票会拴在一起？共享同一基本面驱动的：两家区域银行（同样的利率环境）、
两家铁塔 REIT（同样的 5G 资本开支）、可口可乐与百事（同一个市场）。

### 5. Engle-Granger 协整检验（`coint`）

**概念**：两步法——先 OLS 回归 `A = α + β×B` 求对冲比率，再检验残差（价差）是否
**平稳**（不漂移、围绕均值震荡）。p 值越小越可能真协整。

**真实例子**：2013–2018 数据第一名 **LNC（林肯国民，寿险）/ MS（摩根士丹利）**：
p = 0.0001，β = 1.48。经济逻辑：都是利率敏感金融股，被"利率"这根绳子拴着。

**两个内置防坑**：
1. **多重检验**：测 11 万对，纯噪声也有 ~5,500 对 p<0.05。看 `p_value_fdr` 列。
   真实数据：105 对原始显著 → FDR-5% 后 **0 对**——大部分"协整"是幻觉。
2. **方向不对称**：回归 A 对 B 与 B 对 A 结果不同，工具双向都测取强的一边（`direction` 列）。

### 6. Johansen 检验（`johansen`）

**概念**：基于 VECM，方向无关，可检验 3+ 只股票。

**进阶玩法——协整篮子**：三家航空公司两两不协整，但 `AAL − 0.5×DAL − 0.7×UAL`
可能平稳。Johansen 的特征向量给出权重。三腿价差破 −2σ → 买 AAL、按权重空另两只。

### 7. 半衰期（`half_life`）—— 决定赚不赚得到钱

**概念**：价差偏离后**回归一半平均需要几天**。AR(1) 回归
`Δspread = α + β×spread(昨天)`，半衰期 = −ln(2)/β。

**为什么重要**：协整说"会回归"，半衰期说"**多久**回归"：
- 持仓周期 ≈ 1~2 个半衰期
- 资金效率：HL=17 天一年滚 ~10 轮；HL=170 天一年 1 轮，年化差 10 倍
- 成本覆盖：HL=2 天的价差波动太小，往返费用吃掉利润

**筛选甜蜜区：5 < HL < 60 天**（漏斗默认值）。

**输出即开仓信息**：`half_life_days / kappa / spread_mean / spread_std / z_score`——
z_score 是当前价差偏离的标准差倍数，**直接就是交易信号**（见第九章）。

### 8. Hurst 指数（`hurst`）—— 价差的性格测试

**概念**：序列是均值回归还是趋势，范围 0~1：
- **H < 0.5** 均值回归（涨了倾向跌回来）→ 配对交易要的
- H = 0.5 随机游走（不可预测）
- **H > 0.5** 趋势（涨了继续涨）→ 动量策略要的

**作用**：对协整的**二次确认**（从波动缩放规律这个完全不同的角度验证）。
LNC/MS 价差 Hurst = 0.27，与协整结论互相印证。
**反向用法**：动量策略筛 H > 0.6。

## 三、领先-滞后类

### 9. 互相关函数（`cross_corr`）

**概念**：比较 A 的今天与 B 的 k 天前。corr(A今天, B昨天) 高 → B 领先 A 一天。

**作用**：发现信息传导链。经典模式：行业龙头先动 → 小盘同行 1~2 天跟上。

**交易举例（跟随策略）**：发现 corr(小盘X今天, 龙头昨天)=0.4、lag=1。
龙头今天大涨 3% → 收盘前买 X → 明天补涨时卖。0.4 不是每次都对，靠重复次数赢。

> ⚠️ **ADR 陷阱（看 `has_adr` 列）**：TSM"领先"台湾本地股一天纯属时区假象
> （美股收盘时亚洲未开盘），不是可交易信息。

### 10. Granger 因果（`granger`）

**概念**：把 B 的历史加入预测 A 的方程，若显著提高精度 → "B Granger-causes A"。
与互相关的区别：控制了 A 自己的历史，问"B 是否有**增量**信息"。有方向、双向分测。

**交易举例**：若"铜价 Granger-causes FCX，最佳滞后 2 天"成立 → 铜两日累涨 >2%
→ 做多 FCX。大规模扫描看 `p_value_fdr`。

### 11. DTW 动态时间规整（`dtw`）

**概念**：允许时间轴拉伸的形态相似度——A 三天走完的形态 B 五天走完，DTW 仍认为像。
距离越小越像。

**作用**：找"节奏不同但剧本相同"的股票（供应链上下游传导有快慢）。
已内置 Sakoe-Chiba 窗口（±10 天），不允许"今天匹配三年前"。

## 四、因子类 —— 把"市场"从噪声里剥出来

### 12. Beta（`beta`）

**概念**：`股票收益 ≈ α + β×市场收益`。β=1.5：大盘涨 1% 它平均涨 1.5%。

**交易举例（市场中性对冲）**：看好 NVDA 的 alpha 但不想赌大盘。NVDA β=1.8：
买 $100k NVDA + 空 $180k SPY → 大盘涨跌净影响 ≈ 0，只赚 NVDA 跑赢市场的部分。

### 13. 滚动 Beta（`rolling_beta`）

**概念**：β 不是常数（2020-03 很多股票 β 翻倍）。输出 `last`（当前值——对冲用这个，
不是 5 年平均）和 `std`（稳定性——std 大要更频繁再平衡）。

### 14. 残差相关（`residual_corr`）—— 机构级筛选的秘密

**概念**：所有股票都跟着大盘动，任何两只都"看起来相关"。先把每只对市场（和行业 ETF）
回归取残差，再对残差算相关——**市场解释不了的共同驱动**。

**实测验证**：剔除市场+行业因子后，普通行业股的残差相关掉到 ≈0；藏有共同驱动的对子
保持 0.63——信号与噪声干净分开。

**筛选升级**：高 Pearson + 高残差相关 = 真同质对；高 Pearson + 低残差相关 = 只是
都跟着大盘混的，剔除。

```bash
stockcorr analyze --tickers sp500 --metrics residual_corr \
    --benchmark SPY,XLK,XLF,XLE,XLV --start 2023-01-01 --end 2026-06-01
```

### 15. 下行 Beta（`downside_beta`）

**概念**：只用大盘下跌日算的 β。`asymmetry = 下行β/上行β` > 1.3 的股票
"平时温顺、崩盘凶残"。

**交易举例（风控）**：构建防御组合时按 asymmetry 再筛一遍，剔除高不对称股——
否则"防御组合"会在熊市现出原形。

## 五、波动率/尾部类 —— 危机时谁和谁一起死

### 16. 尾部相关（`tail_dep`）

**概念**：`λ = P(A 暴跌 | B 暴跌)`——B 处于最差 5% 日子时 A 也在最差 5% 的条件概率。

**为什么不能用普通相关**：平时相关 0.3 的资产，崩盘时集体飙到 0.9
（"最需要分散时分散失效"）。全样本平均完全掩盖这个现象。

**交易举例（压力测试）**：组合里 10 只"低相关"股票，尾部相关一查 7 只两两 >0.5
→ 平时分散、崩盘时是一个仓位 → 减仓或买指数 put 对冲共同尾部。

> 输出带 `n_tail_obs` 和置信区间：5 年数据只有 ~63 个尾部样本，别对单个数字过度自信。

### 17. 波动率相关（`vol_corr`）

**概念**：不看方向，看**波动率水平**是否同步。期权交易者用它判断：买 A 的期权时
B 的隐含波动率会不会跟着贵。默认非重叠窗口（重叠会系统性高估）。

### 18. DCC-GARCH（`dcc`）

**概念**：把相关性本身建模成**每天变化的序列**（GARCH 滤波 + 动态相关方程）。
输出 `value`(均值)/`last`(当前)/`max`/`min`。

**交易举例**：SPY/TLT 的 DCC 长期为负（-0.3），是 60/40 组合的基石。当 `last` 翻正
并持续（如 2022 加息周期）→ 债券不再对冲股票 → 60/40 失效，转向商品/现金对冲。

## 六、非线性类

### 19. 互信息（`mutual_info`）

**概念**：信息论指标——知道 B 后对 A 的不确定性减少多少，捕捉**任何形状**的依赖。
已归一化到 [0,1)，可直接与 |Pearson| 对照（原始 nats 在 `mi_nats` 列）。

### 20. 距离相关（`distance_corr`）

**概念**：等于 0 当且仅当完全独立（Pearson=0 不保证独立）。

**实战用法（`nonlinearity` 列）**：`nonlinearity = dCor − |Pearson|`。
差值大（如 dCor 0.5 / Pearson 0.1）= 存在纯非线性关系，画散点图人工看。

**交易举例**：个股 vs VIX——平时无线性关系，但 VIX>35 时几乎所有股票暴跌
（阈值型关系）。Pearson 看不见，dCor 看得见。发现后构建条件规则：
VIX 突破 30 → 自动减仓 50%。

## 七、时变类 —— 关系会变，策略要跟着变

### 21. 滚动相关（`rolling_corr`）

**概念**：60 天滑窗持续重算相关性。输出 mean/std/min/max + `stable` 标志。

**核心洞察**：**稳定比高更重要**。均值 0.75/std 0.08（任何时候都靠谱）远胜
均值 0.85/std 0.30（开仓时不知道处于哪种状态）。漏斗最后一关就是它。

### 22. Regime 条件相关（`regime_corr`）

**概念**：按市场状态分组（如 VIX>20 为高波动期）分别算相关。

```bash
stockcorr analyze --metrics regime_corr --regime '^VIX:20' ...
```

**交易举例**：配对 A/B 低波动期相关 0.8、高波动期掉到 0.4 → 加开关：
**VIX>25 停止开新仓**。反之危机期相关性更强的对子（避险资产）可只在危机期交易。

### 23. 突变检测（`breakpoints`）

**概念**：PELT 算法自动找滚动相关的**结构断裂点**，输出断裂次数 + 最近断裂日期。

**交易举例**：KMB/PG 配对做了三年。工具报告 `last_break_date=2025-11-03`，查当天
新闻：KMB 宣布跨界收购——商业模式变了，绳子断了。**立即平仓退役这个对子**，
不要等价差"回归"——它可能再也不回归。价差发散是配对交易最大亏损来源，
突变检测是预警器。

## 八、其他相似度

### 24. Gatev 距离（`gatev_distance`）

**概念**：1998 年开创配对交易学术研究的原始方法：价格归一化到起点=1，
算轨迹的欧氏距离平方和。越小越像。

**原版交易规则（教科书级）**：
1. 形成期 12 个月：全市场算距离，取最小的 20 对（工具默认 252 天形成窗口）
2. 交易期 6 个月：价差破 ±2σ 开仓做收敛
3. 收敛平仓；到期未收敛强制平仓；滚动重复

**与协整怎么选**：Gatev 简单稳健无参数但粗糙；协整精确但工序多。
**双筛**（两种方法都入选）置信度最高。

### 25. 层次聚类（`cluster`，支持残差模式）

**概念**：以 1−|corr| 为距离把宇宙自动分群。提供 benchmark 时自动用**残差相关**聚类
（否则所有股票被大盘黏成一团——实测中 24 只行业股全进了同一簇）。

**两大用途**：
1. 缩小配对搜索：只在簇内找协整对，11 万对变几千对
2. **发现 GICS 分类错误**（真实 alpha 来源）

**真实发现**（2013–2018 数据）：
- AMZN（官方：零售）→ 聚到互联网簇——交易特性是科技股
- AXP（官方：金融）→ 聚到可选消费簇——驱动是消费支出不是利差
- ADP（官方：工业）→ 聚到 IT 簇——payroll 软件公司

**交易价值**：行业中性策略按 GICS 对冲；知道 AXP 实际是消费股，用 XLY 而非 XLF
对冲它，你的"中性"比别人更真。

## 九、完整实战：一笔配对交易的全生命周期

### 第一步：筛选（每月一次）

```bash
stockcorr screen --tickers sp500 --start 2021-06-01 --end 2026-06-01 --out pairs.csv
```

漏斗自动执行：11 万对 → Pearson 预过滤 → 协整 → 前后半样本验证 → 半衰期 5~60 天
→ Hurst<0.5 → 滚动相关稳定。真实输出第一名：

> **LNC/MS：β=1.48，半衰期 17.3 天，Hurst 0.27，当前 z = −2.01**

### 第二步：读懂信号

z = −2.01：当前价差 `LNC − 1.48×MS` 比历史均值**低 2 个标准差**——LNC 相对 MS
异常便宜。赌注：价差回归均值。

### 第三步：开仓（金额按对冲比率配）

单笔资金 $50,000：买入 LNC ≈ $29,700，卖空 MS ≈ $20,300（由 β=1.48 与两者价格换算）。
之后大盘涨跌 3% 两腿盈亏基本抵消——**只暴露在价差上**。

### 第四步：退出规则（开仓前写死）

| 情形 | 规则 | 依据 |
|------|------|------|
| 止盈 | z 回到 ±0.5 内平仓 | 均值回归完成 |
| 止损 | z 突破 ±3.5 无条件平仓 | 协整可能已断裂 |
| 时间止损 | 持仓超 2×半衰期 ≈ 35 天未回归，平仓 | 回归速度不对 = 模型失效 |
| 结构止损 | breakpoints 报新断裂 / 任一公司重大公告 | 绳子断了 |

### 第五步：预期核算

价差 σ ≈ $2.00（`spread_std` 列），z 从 −2 回到 0 赚 2σ；半衰期 17 天 → 预期持仓
3~5 周 → 一年可滚 6~8 次。扣 borrow 费、佣金、滑点后看净期望。

### 第六步：组合风控

- 同时持有 5~10 个**不同行业**的配对。终选名单里金融对太多（LNC/MS、JPM/SCHW、
  KEY/MTB 高度同源）**只能选 1~2 个**，否则全组合在赌利率
- 用 `tail_dep` 检查各配对价差之间的尾部相关
- 每月重跑 screen，淘汰 `stable=False` 或出现 breakpoint 的对子

### 第七步：回测验证（先于实盘）

```bash
# 在更早的窗口选对，在之后的窗口回测 —— 避免前视偏差
stockcorr screen   --input-csv panel_2013_2015.csv --out pairs.csv
stockcorr backtest --input-csv panel_2015_2018.csv --pairs-csv pairs.csv \
    --entry-z 2 --exit-z 0.5 --stop-z 3.5 --cost-bps 5 --plot equity.png
```

回测器是逐日 walk-forward 的：每天只用**当天之前**的滚动窗口估计 β/μ/σ，
持仓期间参数冻结（现实中你交易的是固定股数比），完整实现第四步的四类退出规则，
并双边扣成本。输出每笔交易明细 + 组合权益曲线 + 夏普/最大回撤/胜率。

## 十、最后的清醒剂

1. **历史协整 ≠ 未来协整**。AET 后来被 CVS 收购退市——任何配对都有"绳子被剪断"
   的一天，止损纪律比选对更重要。
2. **FDR 教给我们的事**：105 个"显著"对严格标准下 0 个过关。统计显著性是廉价的，
   **经济逻辑 + 样本外验证**才贵。永远问：这两家公司**为什么**该拴在一起？
   答不出来就不做。
3. **成本是隐形对手**：每轮 4 笔交易 + 做空融券费。半衰期短、轮次多的策略对成本
   极度敏感（回测时把 `--cost-bps` 调高一倍看策略还活不活着）。
4. **选对与交易必须分窗**：用同一段数据既选对又回测 = 前视偏差，结果必然好看且必然
   不可复现。
